# GREEN-API Chat

Простой чат на React для отправки и получения текстовых сообщений в MAX и WhatsApp через GREEN-API.

## Запуск

```bash
npm install
npm run dev
```

Запустите сайт, выберите мессенджер и введите `idInstance` и `apiTokenInstance` своего инстанса GREEN-API.

В настройках инстанса GREEN-API установите «Да» для пунктов:

- «Получать уведомления о входящих сообщениях и файлах»;
- «Получать уведомления о сообщениях, отправленных с телефона»;
- «Получать уведомления о сообщениях, отправленных с API»;
- «Получать уведомления о статусах отправленных сообщений».
